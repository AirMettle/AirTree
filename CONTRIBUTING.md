# Contributing to AirTree

Thank you for your interest in AirTree.

AirTree's source is published for transparency, evaluation, and non-commercial
use under the [AirMettle Noncommercial License](LICENSE). It is
**source-available, not open-source**: AirMettle develops AirTree internally,
and **we do not accept external code contributions**.

That said, your feedback genuinely shapes the project. This guide explains the
ways you can help and how to get the most useful response.

## How you can help

We welcome:

- **Bug reports** — [open an issue](https://github.com/AirMettle/AirTree/issues/new/choose)
  and choose **Bug report**.
- **Feature requests and improvement ideas** —
  [open an issue](https://github.com/AirMettle/AirTree/issues/new/choose) and
  choose **Feature request**.
- **Documentation problems** — found a typo, a broken link, or an unclear
  section? Please open an issue describing it. We make the edit internally (see
  *What we don't accept* below).
- **Questions and usage help** — email
  [support@airmettle.com](mailto:support@airmettle.com).

## What we don't accept

- **Pull requests and code patches — including documentation fixes.** Because
  AirTree is distributed under a noncommercial, source-available license and
  incorporates patent-pending technology, all changes are made by AirMettle.
  Pull requests (code or docs) will be closed with a pointer to open an issue
  instead. This is not a reflection on your change — reporting the problem in an
  issue is the fastest way to get it addressed, and it keeps the project's
  licensing and intellectual property clean.

Because we do not merge outside code, there is **no Contributor License
Agreement (CLA) or Developer Certificate of Origin (DCO)** to sign.

## How to file a useful bug report

The more of the following you can include, the faster we can reproduce and fix
the problem:

- AirTree version (`airtree --version`)
- Operating system and architecture (e.g. Ubuntu 22.04 x86_64, macOS arm64)
- The schema / config involved, if applicable (e.g. `1DxP`, `2DxP`)
- How you built or installed AirTree
- Minimal steps to reproduce, including the shape of your input data
- What you expected to happen, and what actually happened (exact error text or
  output)

## Security issues

Please **do not** report security vulnerabilities through public issues. See
[SECURITY.md](SECURITY.md) for how to report them privately.

## Commercial, government, and enterprise use

The license permits non-commercial use only, and **use by government
institutions (including national laboratories) is treated as commercial use**.
For commercial licensing, government use, enterprise support, or partnership
inquiries, contact [info@airmettle.com](mailto:info@airmettle.com).

## Community expectations

Please be respectful and professional in issues and discussions. We want this to
be a welcoming space for everyone seeking help or reporting a problem.
Harassment, abuse, personal attacks, and other disruptive behavior are not
tolerated, and may result in comments being removed or the responsible accounts
being blocked from the project.
